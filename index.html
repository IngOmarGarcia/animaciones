Preguntas frecuentes

¿Tiene costo?

No. Crear y compartir animaciones es gratis.

¿La otra persona necesita instalar algo?

No necesita instalar una aplicación. El enlace requiere un navegador moderno con JavaScript y una conexión para cargar la escena.

¿Puedo copiar el código de las animaciones?

En las escenas que ofrecen esta opción, toca Ver o descargar el código: es un solo archivo HTML que se abre con doble clic, y puedes cambiarle el nombre y el mensaje. Ver el código del ramo de flores amarillas.

¿Guardan mi mensaje?

El editor conserva un borrador en esta pestaña. El mensaje viaja codificado dentro del enlace, sin cifrado, y la URL puede aparecer en registros del alojamiento. Cualquier persona que tenga el enlace puede verlo, así que compártelo solo con quien quieras.
