# Crystal Heartbeat · paquete previsto

Inventario preparatorio del proyecto completo, con volumen implícito, fragmentos de cristal, superficie fusionada, transmisión, energía interior y deformación tridimensional por latidos. No hay compra, descarga comercial ni desbloqueo implementados.

El código de la obra y sus recursos procedurales son originales de OGR/ViralCSS. Three.js 0.180.0 conserva su licencia MIT en `js/vendor/three/LICENSE`; esa licencia no concede nuevos permisos sobre el código original de ViralCSS. La imagen de respaldo procede del renderizador real.

Antes de distribuir un paquete se deberán revisar el inventario, la documentación y sus condiciones. El manifiesto incluye los módulos compartidos necesarios, sin duplicar la dependencia fijada. Ocultar el editor público no impide inspeccionar el código ejecutado en el navegador.
