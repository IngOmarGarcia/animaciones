Mariposas de neón

Mariposas de luz que se unen para encender un corazón.

Personalizar esta escena

Prueba la escena

La vista previa usa texto de ejemplo. Se carga cuando la solicitas.

La reunión sucede automáticamente. El editor permite elegir dos colores para las mariposas; algunos acentos del corazón conservan sus tonos originales.

Qué ocurre en la escena

Mariposas de varios tonos vuelan con rastros de luz. Se reúnen en el contorno de un corazón que se enciende y permanece acompañado por sus alas.

Qué puedes personalizar

  • Nombre y mensaje de hasta 40 y 140 caracteres en el formulario.
  • Puedes reemplazar la frase inicial «Me haces sentir mariposas 🦋». Si la dejas vacía, se conserva la sugerencia de esta escena.
  • Firma opcional y cinco tipografías para el texto normal. Las letras construidas con partículas conservan su forma.
  • Dos colores opcionales para los elementos de luz. Puedes desactivar la paleta personalizada para recuperar el diseño original; el fondo y algunos detalles mantienen sus colores.

Qué verá el destinatario

El enlace abre esta misma animación con tu nombre, frase y firma. No necesita crear una cuenta ni instalar una aplicación.

Una frase sobre ilusión o cariño con mariposas luminosas.

El editor genera un enlace para copiar o compartir por WhatsApp. Quien tenga ese enlace puede abrirlo: evita incluir información privada.
