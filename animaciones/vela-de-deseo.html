Vela de deseo

Pide un deseo, toca para soplar y el humo se vuelve magia.

Personalizar esta escena

Prueba la escena

La vista previa usa texto de ejemplo. Se carga cuando la solicitas.

Toca para simular el soplido. No se usa el micrófono; si nadie toca, la vela también se apaga después de una espera.

Puedes tocar la escena o usar Intro o Espacio con el lienzo enfocado. En una pulsación mantenida, conserva la tecla presionada.

Qué ocurre en la escena

Una vela permanece encendida antes de que su llama se apague. El humo se convierte en pequeñas chispas doradas que acompañan el mensaje.

Qué puedes personalizar

  • Nombre y mensaje de hasta 40 y 140 caracteres en el formulario.
  • Puedes reemplazar la frase inicial «Que se cumplan todos tus deseos 🕯️». Si la dejas vacía, se conserva la sugerencia de esta escena.
  • Firma opcional y cinco tipografías para el texto normal. Las letras construidas con partículas conservan su forma.

Qué verá el destinatario

El enlace abre esta misma animación con tu nombre, frase y firma. No necesita crear una cuenta ni instalar una aplicación.

Un deseo de cumpleaños o un mensaje breve con un cierre de luz.

El editor genera un enlace para copiar o compartir por WhatsApp. Quien tenga ese enlace puede abrirlo: evita incluir información privada.
