Cómo preparar una dedicatoria

  1. Abre una ficha para probar la secuencia y conocer el gesto que necesita.
  2. Entra en Personalizar. Las frases de partículas conservan sus palabras; las escenas con mensaje editable permiten escribir el tuyo.
  3. Mira la vista previa hasta el final, crea el enlace y envíalo. El destinatario no necesita registrarse.

Para contar una historia con varios recuerdos, busca Carta y recuerdos. Para un saludo inmediato, una escena automática empieza sin pedirle un gesto al destinatario.
