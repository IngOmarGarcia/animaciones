Términos de Uso

Última actualización: 4 de octubre de 2026.

Responsable y alcance

OGR es el creador y administrador de ViralCSS. La plataforma permite visualizar, personalizar, dedicar y compartir animaciones interactivas mediante enlaces. Algunas escenas también ofrecen código descargable.

Estas condiciones establecen los usos permitidos de las animaciones y del código original de OGR/ViralCSS. Descargar un archivo o modificarlo no transfiere su autoría ni los derechos sobre el trabajo original.

Uso permitido del código descargable

Puedes descargar, ejecutar, estudiar y modificar el código disponible en ViralCSS únicamente para uso personal, educativo y experimental.

Este permiso permite explorar cómo funciona una escena, ejecutarla en tu dispositivo y realizar modificaciones dentro de esos usos. No concede por defecto autorización para usos comerciales ni para distribuir el archivo original o una versión modificada.

Usos que requieren autorización

Sin autorización, no está permitido:

  • Utilizar comercialmente las animaciones o el código.
  • Vender las animaciones o el código, originales o modificados.
  • Redistribuir el código original o modificado.
  • Republicar las animaciones como propias o como parte de otra colección o plataforma.

Para cualquier uso comercial o redistribución, solicita autorización a través del correo de contacto. Enviar una solicitud no equivale a obtener autorización.

Atribución de trabajos derivados

Cuando muestres públicamente un trabajo derivado, debes incluir una atribución visible a ViralCSS. Por ejemplo: «Basado en una animación de ViralCSS», con un enlace a ViralCSS.

La atribución no sustituye la autorización necesaria para un uso comercial o una redistribución. Tampoco permite presentar una animación de ViralCSS como una creación original propia.

Autoría y derechos

Los derechos sobre las animaciones y el código original permanecen con OGR/ViralCSS. Las modificaciones realizadas para los usos permitidos no eliminan esos derechos sobre el trabajo original.

Personalizar y compartir por enlace

Puedes utilizar las funciones del sitio para preparar y compartir una dedicatoria por enlace. Compartir ese enlace no equivale a redistribuir el código descargable ni concede permisos adicionales sobre las animaciones.

Para conocer cómo se tratan los textos, las fotografías opcionales y los enlaces compartidos, consulta el Aviso de privacidad.

Contacto y solicitudes de autorización

Para consultar estas condiciones o solicitar autorización para un uso comercial o redistribución, escribe a viralcss11@gmail.com. Describe la animación y el uso que deseas realizar.
